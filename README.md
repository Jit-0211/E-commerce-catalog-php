# ShopCatalog - E-commerce Product Catalog

PHP and MySQL mini project (BCA 5th semester, PCA2, Sec B).

## Features
- Browse products by category
- Search products by name or description
- Product detail page with description, price and image
- Admin login with password hashing
- Admin can add, edit and delete products and categories
- Product image upload
- Responsive design for mobile and desktop

## Tech stack
PHP, MySQL, HTML, CSS

## Setup
1. Copy the project folder to C:\xampp\htdocs\catalog
2. Start Apache and MySQL in XAMPP
3. Open phpMyAdmin and import database.sql
4. Open http://localhost/catalog/ in the browser
5. Admin panel: http://localhost/catalog/admin/login.php
   Username: admin
   Password: admin123

## Folder structure
- index.php: home page with category filter and search
- product.php: product detail page
- database.sql: tables and sample data
- css/: stylesheet
- includes/: database connection, header and footer
- admin/: admin login, dashboard, product and category management
- uploads/: uploaded product images
